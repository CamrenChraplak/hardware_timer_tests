# Arduino IDE

This test environment uses [Arduino IDE](https://www.arduino.cc/en/software/) to test the [Universal Hardware Timer](https://github.com/CamrenChraplak/universal_hardware_timer) library. Output is printed using Arduino's `Serial.print` functionality at a baud rate of `115200`.

## Setup:

- Install the Universal Hardware Timer library into Arduino IDE
- Build and run on chosen platform
- Monitor through `Serial Monitor` in Arduino IDE
