# Universal Hardware Timer Tests

This repository contains tests for the [Universal Hardware Timer](https://github.com/CamrenChraplak/universal_hardware_timer) library.

## Included test environments:
- Arduino IDE (arduino_ide_hardware_timer)
- ESP-IDF (esp_idf_hardware_timer)
- Raspberry Pi Pico SDK (pico_sdk_hardware_timer)
- PlatformIO (platformio_hardware_timer)
